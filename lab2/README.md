# Лабораторна робота 2

Тема: CSS-фреймворк Tailwind CSS. **Варіант 3** (номер у списку групи: 11).

Односторінковий макет UnitLab містить чотири секції з текстом, зображенням,
полями та кнопками. Сітка має одну колонку на телефоні, дві від 768 px та
чотири від 1024 px. Навігація веде до секцій; футер містить контакт автора.

Використано Tailwind CSS **3.4.17**, оскільки завдання передбачає
`tailwind.config.js` і директиви `@tailwind`. Конфігурація додає власні кольори,
шрифт, брейкпоінт `wide` 1440 px, відступ `18` і радіус `card`; усі вони
використані в HTML. [Документація встановлення](https://v3.tailwindcss.com/docs/installation).

```powershell
npm ci
npm run build
npm start
```

Відкрити http://127.0.0.1:4173/lab2/ або безпосередньо `lab2/index.html`.
Зібраний `styles.css` включено до репозиторію; сторінка працює без CDN та інтернету.
Ця робота демонструє статичний макет. Інтерактивний конвертер створюється в лабораторній №3.
