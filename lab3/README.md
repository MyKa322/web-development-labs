# Лабораторна робота 3

Тема: Вступ до мови JavaScript. Робота з DOM елементами та подіями.
**Варіант 3** — конвертер довжини на основі макета лабораторної №2.

## Можливості

- Два текстові поля: вхідне значення та результат (тільки для читання).
- Два списки одиниць: мм, см, м, км, заповнені з константи `UNITS`.
- Кнопка «Перетворити» та підтримка відправлення форми клавішею Enter.
- Кожне успішне перетворення додається до історії як HTML-елемент.
- Кнопка «Очистити» видаляє всю історію та скидає лічильник.
- Перевірка порожніх, від’ємних, нечислових та завеликих/замалих значень.
- Десяткова кома й крапка, нуль, науковий запис; показ до 12 значущих цифр.
- Обмін одиниць кнопкою «Поміняти одиниці».

Формула: `result = value * (UNITS[from].factor / UNITS[to].factor)`.
Наприклад, `2,5 км → м` дає `2 500 м`. Історія зберігається протягом поточної
сесії сторінки; перезавантаження її скидає. Числа обчислюються як JavaScript
`Number`, тому форматування приховує звичайні похибки двійкової арифметики.

```powershell
npm ci
npm run build
npm start
```

Відкрити http://127.0.0.1:4173/lab3/ або `lab3/index.html` без сервера.
Вихідний код: `index.html`, `app.js`, `assets/measure.svg`; зібраний CSS уже включено.

## Перевірка

```powershell
npm test
```

Тести запускають локальний сервер та браузер Microsoft Edge у фоновому режимі.
Якщо Edge не встановлено: `npx playwright install chromium`, після чого
в `playwright.config.cjs` прибрати параметр `channel: 'msedge'`.

Документація: [DOM](https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model),
[preventDefault](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault).
