# Функції та масиви JavaScript

Робота №4, варіант 3 за номером 11 у списку. Відкрийте сторінку через локальний HTTP-сервер.
Виконані IIFE з визначенням платформи, `reduce`, об’єднання двох масивів по десять чисел,
`Map` із `for…of`, `call` і `apply`, замикання `createMultiplier`.
Результати видно на сторінці та в консолі. Лічильник враховує кодові точки Unicode.

```powershell
npm start
npm run test:unit
```
