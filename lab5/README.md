# Керування паркінгом

Робота №5, варіант 1 за номером 11 у списку. `Car`, `Truck` та `Motorcycle` успадковують
`Vehicle`. Об’єкти `ParkingSpot` зберігають зайнятість у приватному полі, `ParkingLot`
керує місцями й часом паркування. Мотоцикл спершу отримує мотоциклетне місце,
потім може зайняти автомобільне. Вантажівці потрібні два сусідні автомобільні місця.
Операція відхиляється повністю, якщо відповідних місць немає.

Вебсторінка показує вільні місця, припарковані номери та тривалість у секундах.
Повторне паркування того самого номера й звільнення відсутнього автомобіля дають повідомлення про помилку.
Перезавантаження сторінки очищає демонстраційний стан.

```powershell
npm start
npm run test:unit
```
