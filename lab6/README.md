# Консольні програми PHP

Робота №6, завдання 1, 2 і 3. Потрібен PHP 8.0 або новіший.

```powershell
php lab6/guess.php
php lab6/rps.php
php lab6/calculator.php
php lab6/tests.php
```

У грі на вгадування доступні сім спроб. Помилкове введення не витрачає спробу.
«Камінь, ножиці, папір» триває три раунди. Калькулятор підтримує `+ - * / ** %`,
перевіряє ділення на нуль і формат виразу. Для виходу введіть `q` або завершіть потік введення.
Залишок `%` обчислюється для цілих чисел. У коді немає `eval`.

Тести охоплюють усі дев’ять пар вибору в другій грі, виграш і ліміт спроб у першій,
арифметику та помилки калькулятора. Фіксоване загадане число задається лише для відтворюваної перевірки.
