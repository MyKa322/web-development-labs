# Форми та база MySQL

Журнал вимірювань UnitLab продовжує тематику конвертера з робіт №2–3.
Форма надсилає назву, примітку, одиницю, довжину та email методом POST.
`list.php` читає дані з MySQL і сортує їх за параметрами GET.
Спільні шапку й підвал підключено через `require`, функції бази та валідації винесено в `app`.

Потрібні Apache, PHP 8.0+ з розширеннями `pdo_mysql` і `mbstring`, MySQL.
Імпортуйте `database/schema.sql` у базу `unitlab` і задайте змінні середовища
`DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` для PHP.
У цьому робочому середовищі сервер запускає `work/start-web-stack.ps1` з кореня лабораторних,
адреса сторінки: `http://127.0.0.1:8088/lab7/`.

Паролі не входять до репозиторію. Запити використовують PDO з вимкненою емуляцією підготовки,
виведення екранується через `htmlspecialchars`, операції POST перевіряють CSRF-токен.
Сортування обмежене списком дозволених колонок. У разі помилки поля зберігають введені значення.
