# Журнал вимірювань MVC

Робота №8 розширює журнал із №7 редагуванням та видаленням записів у тій самій таблиці MySQL.
Кожен клас розміщено в окремому файлі. Залежності створюються у вхідному `index.php`.

| Компонент | Відповідальність |
| --- | --- |
| DatabaseConnection | Singleton для PDO в межах одного PHP-запиту |
| Measurement, MeasurementFactory | Дані вимірювання та створення об’єкта |
| MeasurementRepository | Підготовлені запити до MySQL |
| MeasurementValidator, FormHandler | Перевірка та підготовка даних форми |
| MeasurementController | Маршрути, HTTP-коди та вибір шаблону |
| views | HTML-форма, список, спільні шапка й підвал |

Налаштування сервера й бази описане в [роботі №7](../lab7/README.md).
Відкрийте `http://127.0.0.1:8088/lab8/`. Редагування заповнює форму даними вибраного запису.
Додавання, оновлення та видалення використовують POST і CSRF-токен. Після успіху сервер
повертає перенаправлення 303. Неправильні дані дають 422, недійсний токен 403,
відсутній запис 404, спроба видалити через GET 405.
